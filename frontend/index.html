AI • Legal Triage • Indian Law

Turn a legal problem into a clearer next step.

Vidhi Saarathi AI is an academic prototype that uses Gemini-powered analysis to turn plain-language legal questions into structured legal-domain, priority and action-oriented information, with supporting document and professional-routing workflows.

Current implementation

Gemini at the core, support workflows around it

The working repository uses Node.js + Express and Google Gemini API access. It also contains an optional ML service interface, but no standalone trained ML model is included here.

01 · IntakePlain-language legal issue from the user.

System workflow

How the prototype works

The repository keeps the generative-AI analysis layer central while separating supporting authentication, document and lawyer workflows.

01 · Input

Describe the legal issue

The user explains the situation in ordinary language without needing legal terminology.

02 · AI analysis

Gemini structures the response

The backend asks Gemini for legal-domain context, priority, relevant law and practical next steps.

03 · Navigation

Connect information to action

The response is designed to help a user understand what kind of professional specialization may be relevant.

Document workflow

Legal documents

The broader backend contains a protected PDF workflow with storage and text extraction. This demo page intentionally avoids pretending that unauthenticated public upload is secure.

PDF / FIR

Upload and extract

Authenticated document upload can store the file and extract text before sending content for AI analysis.

Privacy

Keep legal records protected

Do not use a public demo deployment for confidential case files without private storage and access control.

Output

Structured document understanding

The intended response includes document type, parties, summary, applicable law, issues and suggested actions.
